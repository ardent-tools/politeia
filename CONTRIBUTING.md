# Contributing

Contributions should preserve the constitutional and semantic boundaries in [`AGENTS.md`](AGENTS.md) and [`START_HERE.md`](START_HERE.md). Discuss changes that alter the ontology, authority model, wire compatibility, or trusted computing base before implementation, and record accepted architectural changes as ADRs.

By submitting a contribution, you represent that you have the right to license it and agree that it is provided under the repository's [Mozilla Public License 2.0](LICENSE). No separate contributor license agreement is required unless the project states otherwise before accepting the contribution.
