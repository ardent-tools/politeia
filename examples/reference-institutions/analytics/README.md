# Synthetic analytics institution

This public fixture represents a small analytics institution. It is disjoint
from the software-development fixture: it has distinct institutional,
workspace, trust-domain, and signing identities. Its facts are synthetic and
do not describe a customer, data set, or production system.

## Approved institutional knowledge

- The source population is an explicit manifest of the public service,
  schema, migration, and release metadata.
- The analysis runbook requires an owner-approved correction for a changed
  interpretation; the original approved record remains preserved evidence.
- The operational worker can execute the deterministic canary only after a
  verified generation is active.
- The verifier is independent of the temporary commissioner and binds an
  attestation to the selected sources and active generation.

## Runbook facts

- Installation is local to the institution and uses PostgreSQL plus a private
  Unix socket.
- Commissioner revocation removes capture and authoring authority without
  stopping the active operational canary.
- A replacement maintainer recommissions from preserved signed state under a
  new grant.
